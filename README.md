# Password Strength Checker

## Description

Password strength checker is a Python-based project that checks the strength of a password based on different security criteria.

The projects checks-
- Password Length
- Uppercase Letters (A-Z)
- Lowercase Letters (a-z)
- Special Characters (@,#,$)
- Numbers (0-9)

After checking these conditions, the program classifies the password as -

- Weak
- Medium
- Strong

## Features

- User friendly interface
- Password length validation
- Uppercase letter validation
- Lowercase letter validation
- Digit validation
- Special character checking
- Password strength analysis
